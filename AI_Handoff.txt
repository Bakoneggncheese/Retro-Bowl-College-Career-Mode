Retro Bowl College – Project Handoff

Project status
- This workspace contains the compiled Retro Bowl College browser game, its supporting data, and a native-UI high-school career prelude.
- The game should be served over HTTP; opening the files directly may result in missing assets or a blank page.
- The original GameMaker project files are not included. `RetroBowl.js` is the available compiled runtime source and contains the prelude integration.

Launch instructions
1. Open a terminal in the project folder.
2. Run: python3 -m http.server 8000
3. Open http://localhost:8000/ in a browser.
4. If the page does not load, make sure the local server is still running and that the browser is pointed to the correct URL.

High-school player career
- On a new Player career, the native details screen is used for player creation before the season; Coach selection is unchanged.
- School, QB/RB position, and 1-to-3-star rating controls are integrated into the native character-details screen.
- The Player home screen replaces the college division panel with a custom season summary and opens a native high-school schedule popup; the stock League screen is not shown during the high-school season.
- Player careers start at the beginning of the season and play six real on-field matches, skipping any bye weeks while advancing the schedule. School identity and uniform colors are customized for the matches, and the introductory tutorial is skipped.
- After the sixth match, the native recruiting popup presents two college offers and the college-entry rating. The offer selected determines the recruited rating and college attributes.
- Offer choices show the college-entry rating after a tiered star reduction based on the high-school rating. The chosen value sets the created player's initial college attributes.
- RB setup keeps the created player on the RB roster entry rather than the QB entry, and offensive plays in the RB career hand off to the RB using normal running controls. Route grading, coach benching, and autosim are not implemented.
- Player-mode setup does not override the stock button fill color.
- `index.html` displays uncaught runtime errors while allowing the game's own global error handler to run.
- Missing optional locale override files are skipped if their text-file handle cannot be opened, preserving the base-language strings.
- Create a new save and choose Player to test the full high-school season and college handoff.

Notes
- The source available here is the compiled GameMaker JavaScript runtime; the original `.yy`/`.gml` project is not included. Re-exporting the game would overwrite runtime changes made directly to `RetroBowl.js`.
- This is a local browser game and does not require a build step or package install.
- If you want to run it again later, restart the HTTP server with the same command above.
- If a black screen returns, confirm the server is running, reload http://localhost:8000/, and check that the runtime files listed above are reachable under html5game/.
